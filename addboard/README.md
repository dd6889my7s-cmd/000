# addboard — 夫婦のスケジュール共有ボード

朝食のときに二人で今日の予定・やること・今後1週間を確認し、それをホワイトボードの
代わりに **リビングのテレビに常時掲示** するためのアプリです。

- iPad / iPhone / PC から編集ページでメモや予定を入力すると、**テレビの表示に即時反映**されます
- 打ち合わせの後に「やっぱり変更」となっても、手元のスマホからいつでも直せます
- iPhone のロック画面にも、その日の自分の予定・やることを表示できます(Scriptable ウィジェット)

## 全体の仕組み

```
             ┌──────────────────────────────┐
             │  テレビに繋がっている PC      │
             │  ・addboard サーバーを常駐    │
             │  ・ブラウザ全画面で /tv 表示  │
             └──────────▲───────────────────┘
                        │ 家の Wi-Fi(リアルタイム同期)
   ┌──────────┬─────────┴─────────┬──────────┐
   │ iPhone A │      iPad         │ iPhone B │
   │ /edit    │      /edit        │ /edit    │
   │ ロック画面ウィジェット ← /api/board      │
   └──────────┴───────────────────┴──────────┘
```

サーバーは Node.js だけで動きます(npm install 不要)。データは
`data/board.json` に保存されるだけなので、外部サービスに家庭の予定が
出ていくことはありません。

## セットアップ

### 1. サーバーを起動する(テレビに繋がっている PC で)

[Node.js](https://nodejs.org/ja)(LTS 版)をインストールして:

```bash
cd addboard
node server.js
```

起動するとアドレスが表示されます:

```
addboard が起動しました。
  テレビ表示:  http://localhost:8720/tv
  スマホから:  http://192.168.1.20:8720/edit   ← 家の中の他の端末からはこれ
```

### 2. テレビに表示する

テレビに繋がった PC のブラウザで `http://localhost:8720/tv` を開き、
全画面表示(F11、Mac は ⌘⌃F)にします。表示は編集と同時に自動更新されます。

さらに常設らしくするなら:

- **Windows**: タスクスケジューラに「ログオン時に `node server.js`」と
  「`chrome --kiosk http://localhost:8720/tv`」を登録
- **Mac**: ログイン項目に登録、または `launchd` で常駐化
- PC の電源設定でスリープをオフに(表示専用機なら)

### 3. iPhone / iPad から編集する

各自の Safari で `http://<PCのアドレス>:8720/edit` を開き、
共有ボタン →「ホーム画面に追加」。アプリのようにワンタップで開けます。

朝会のときは誰かがこのページでメモを打つだけで、テレビの「今日の朝会メモ」に
大きく映ります。予定・やることもフォームから追加でき、完了・削除もここから。

### 4. ロック画面ウィジェット(任意)

`scriptable/AddBoard.js` の冒頭のコメントに手順を書いています。要点:

1. App Store で **Scriptable**(無料)を入れる
2. スクリプトを貼り付けて、冒頭の `SERVER`(PC のアドレス)と `MY_NAME`(自分の名前)を書き換える
3. ロック画面のカスタマイズで Scriptable ウィジェットを追加する

注意点が2つあります:

- ロック画面の更新頻度は iOS 任せで、**15〜30分おき程度**です(リアルタイムではない)
- 取得できるのは**自宅 Wi-Fi にいる間**だけです。外でも見たいなら
  [Tailscale](https://tailscale.com/)(個人利用無料の VPN)を PC と iPhone に
  入れると、家の外からも同じアドレスで繋がります

「確実にリアルタイムでロック画面に出したい」場合は、後述の
純正カレンダー併用が現実的です。

## 使い方(毎朝の流れ)

1. 朝食中、どちらかが iPad か iPhone で編集ページを開く
2. 話しながら「今日の朝会メモ」に決めたことを打つ → テレビに即時表示
3. 予定・やることをフォームで追加(相手の分も入れられる)
4. 日中に変更が出たら、各自のスマホから直す → テレビも自動で変わる
5. 終わった予定は2週間後、完了したやることは2日後に自動で消えます

## 自作以外の選択肢(比較検討したもの)

| 方法 | テレビ掲示 | 即時反映 | ロック画面 | 備考 |
|---|---|---|---|---|
| **addboard(このアプリ)** | ◎ 専用デザイン | ◎ 秒単位 | △ Scriptable(15分おき) | 自宅内で完結・無料 |
| iCloud 共有カレンダー+リマインダー | △ ブラウザで表示可 | ○ | ◎ **純正ウィジェットが最強** | 通知も鳴る |
| [DAKboard](https://dakboard.com/) | ◎ | ○ | × | 有料プランあり・クラウド |
| [MagicMirror²](https://magicmirror.builders/) | ◎ | ○ | × | Raspberry Pi 向け・構築の手間大 |
| Notion / Google カレンダーを TV で表示 | ○ | ○ | △ | 大画面向けデザインではない |

**おすすめの組み合わせ**: 「時間が決まっている予定」は iCloud の共有カレンダーにも
入れておく(ロック画面の純正カレンダーウィジェット+通知が使える)。
「朝会メモ・やること・一週間の見通しの掲示」は addboard が受け持つ。
ADHD 対策としては、通知(カレンダー)と常時掲示(テレビ)の二段構えが効きます。

## 今後の拡張アイデア

- iCloud / Google カレンダーの予定を読み込んでテレビにマージ表示
- 定例のやること(ゴミ出しの曜日など)の自動繰り返し
- 完了したやることに「えらい!」演出(続けるモチベーション用)
- 時間が近づいた予定をテレビ上で点滅・強調

## 技術メモ

- `server.js` — 依存ゼロの Node.js サーバー(ポート 8720、`PORT` 環境変数で変更可)
- 同期は Server-Sent Events。切断時は自動再接続
- データは `data/board.json`(git 管理外)。バックアップはこのファイルをコピーするだけ
- API: `GET /api/board` / `POST /api/events` / `POST /api/todos` /
  `POST /api/todos/:id/toggle` / `DELETE /api/{events,todos}/:id` / `PUT /api/note`
